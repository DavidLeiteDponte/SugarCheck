# Aplicación para el Monitoreo de Diabetes Tipo 1

La Aplicación es una solución integral diseñada para simplificar el seguimiento diario de la Diabetes Tipo 1. El proyecto combina el registro tradicional de métricas con el análisis inteligente de datos, permitiendo a los usuarios identificar patrones glucémicos, gestionar sus dosis de insulina de forma segura y acceder a información educativa mediante un asistente interactivo.

El objetivo principal es transformar los datos de glucosa e insulina en información accionable para el usuario y reportes claros para el profesional de la salud, priorizando siempre la seguridad y la prevención de riesgos mediante alertas en tiempo real.
